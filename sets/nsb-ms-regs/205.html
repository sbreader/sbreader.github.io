5. BONUS Chemistry Short Answer Using proper chemical nomenclature and indicating the state of each substance as solid, liquid, aqueous, or gas, what is a balanced equation for the reaction in which silver nitrate solution is mixed with sodium chloride solution, producing insoluble silver chloride and sodium nitrate solution?
ANSWER: AgNO3(aq) + NaCl(aq) → AgCl(s) + NaNO3(aq) [NOTE: AQ = AQUEOUS; S = SOLID]
