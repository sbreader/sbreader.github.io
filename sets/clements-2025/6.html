6. TOSS-UP Math Multiple Choice Researchers at Lawrence Livermore National Laboratory are conducting linear regressions. Which of the following is true if the linear regression of a bivariate data set has an r-squared value of 0.81?

X) 90% of the variance in the independent variable is explained by the dependent variable in the regression model
Y) 81% of the variance in the dependent variable is explained by the independent variable in the regression model
