1. TOSS-UP Physics Multiple Choice What equation in physics is used to describe the magnetic field produced by a given current?

2. TOSS-UP Chemistry Multiple Choice Which of the following statements regarding an atomic orbital is false?
W) An atomic orbital is a three dimensional shape
