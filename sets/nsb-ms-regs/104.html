1. TOSS-UP Math Multiple Choice Given that time t has values 0, 1, and 2, and distance d has corresponding respective values 60, 110, and 160, which of the following equations represents the linear relationship between t and d?

ANSWER: X) d = 50t + 60

ANSWER: Y) PT = PA + PB + PC…
