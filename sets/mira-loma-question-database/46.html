1. TOSS-UP Biology Short Answer A cell is found to be missing either DNA polymerase I, DNA polymerase III, DNA ligase, or DNA primase. Given the following description, identify which of these enzymes is missing: The cell has an abnormally high mutation rate on the lagging strand. You extract the nucleoplasm and place it in a vial with DNA and find that there is no 5' to 3' exonuclease activity. Furthermore, you note that there is some RNA-DNA base pairing during the G1 phase. Which enzyme is missing?
ANSWER: DNA POLYMERASE I
