1. BONUS Biology Multiple Choice Which of the following is correct about the small intestine stage in digestion?
W) Cholecystokinin stimulates the pancreas to release sodium bicarbonate
X) Gastrin is created by the small intestine and stimulates the production of gastric juices in the stomach
Y) Sugars enter the bloodstream by being coated with phospholipids to create chylomicrons, which are transported into the hepatic portal vein

4. BONUS Biology Multiple Choice Which of the following explains how the dideoxyribonucleotides terminate a DNA strand?

Y) It has no 5'- OH groups, so the next nucleotide cannot attach
